## PR-branch build-check diagnosis

Cloudflare Workers Builds failed on PR branches while GitHub CI passed and the corresponding `main` builds succeeded. The full retry log on 2026-09-23 shows installation and `bun run build` completed, followed by:

```text
Executing user deploy command: npx wrangler preview
Using redirected Wrangler configuration.
 - Configuration being used: "dist/server/wrangler.json"
 - Original user's configuration: "wrangler.jsonc"
✘ [ERROR] Your Wrangler configuration is missing a `previews` block to run this command.
Failed: error occurred while running deploy command
```

`bunx wrangler preview --name contentos-build-diagnostic --json` reproduced the missing-block error locally without creating a Preview. The repo's `bun run deploy:preview` is a different command: it runs `wrangler deploy` and targets the live Worker. Retrying the unchanged PR build will repeat the failure. Configure a `previews` block with isolated D1/R2 resources and Preview-specific secrets before enabling this check as a release gate; an empty block alone would not provide the app's runtime bindings. This work is deferred because live `main` builds and the canonical smoke test passed.
